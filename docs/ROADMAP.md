# Roadmap

## Near term

- Add origin → visit → snapshot traversal as a single workflow.
- Add recursive directory-tree exploration with depth and object-count controls.
- Add revision-history depth and merge-topology analyses for selected origins.
- Add cached query plans for repeated exploration of large exports.
- Add fixtures generated from a tiny synthetic ORC export for integration tests.

## Research directions

- Compare revision topology across selected software origins.
- Detect unusual archive structures using transparent statistical baselines before model interpretation.
- Build SWHID-centered research notebooks that can export evidence bundles and reproducible query metadata.
- Evaluate whether retrieval over public archive APIs can complement local teaser datasets without requiring privileged infrastructure.

## With deeper archive access

A larger or internal graph environment could support broader ancestry, cross-origin reuse, large-scale software-evolution studies, and richer graph algorithms. Those directions are intentionally not simulated in this public prototype.
